任务：帮我写一个适配手机屏幕（Mobile First）的单页网页计算器，用于计算车辆每周/每年的持有和出行成本。
设计风格：
UI风格：​ 模仿 iOS 风格，圆角卡片（Rounded Cards），柔和的阴影，主色调使用科技蓝（#007AFF）或深绿色（#34C759，用于省钱的数字）。
布局：​ 单列布局，顶部显示总计金额，中间是可折叠的参数分组，底部是图表。字体要大，按钮要好点触。
功能模块：
1. 顶部概览区
显示巨大的“每周预估花费”：¥XXXX 元。
下方小字显示“每年花费”：¥XXXX 元 及 “每公里成本”：X.XX 元/km。
2. 输入参数区（使用 <details> 标签实现折叠分组）
分组一：基础信息
购车价格（滑块或输入框，范围 5w-40w，默认 15）：[====●====]
车辆类型（分段选择器 Segmented Control）：油车 / 电车
年行驶里程（滑块，范围 5000-30000km，默认 12500）：[===●=====]
分组二：持有成本（固定开销）
保险年费（输入框，默认油车4500，电车5000）
停车年费（输入框，默认小区300/月，外出停车80/月）
预估罚单（输入框，默认400元/年）
折旧年限（滑块，默认6年）
残值比例（滑块，默认油车40%，电车35%）
机会成本利率（滑块，默认3%，即理财收益）
分组三：使用成本（变动开销）
油车：百公里油耗（输入框，默认8L） + 油价（输入框，默认7.5元/L）
电车：百公里电耗（输入框，默认15kWh） + 综合电价（输入框，默认0.8元/kWh，含家充和快充混合）
保养费率（输入框，默认油车800元/万公里，电车300元/万公里）
3. 计算结果区
饼图（Chart.js）：​ 展示各项成本占比（折旧、保险、能源、停车等），直观显示“折旧是大头”。
明细列表：​ 列出每周的折旧费、保险费、能源费、停车费等具体数值。
4. 逻辑要求
所有输入项实时联动（onChange），修改任一数值，顶部总计和图表立刻更新，无需刷新页面。
切换“油车/电车”时，相关参数（如保险、折旧、能耗）自动切换为预设的默认值。
代码包含必要的 CSS @media 查询，确保在 iPhone SE 到大屏安卓都能正常显示。
5. 附加功能
底部增加一个“分享结果”的按钮（调用 Web Share API，如果不支持则复制文本）。
代码交付：
请将代码整合在一个 index.html 文件中，内嵌 CSS 和 JavaScript，方便我直接用手机浏览器打开测试。
