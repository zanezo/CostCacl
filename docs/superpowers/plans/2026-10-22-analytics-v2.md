# 统计口径修订

新版按北京时间自然日、匿名浏览器去重。累计值是各日人数之和，不是历史独立访客；同一人跨日重复计入。使用独立 v2 Redis key，旧统计保留，拒绝旧版上报混入。

手机有效测算由开始测算触发；桌面由用户主动修改合法参数并稳定显示结果触发，或主动生成车格卡时补记。初始默认值展示、程序回填不计桌面测算。

访问、测算、卡片生成、点击保存、系统分享成功、反馈、回访分别去重；转化分母为同口径的访问/测算人数。保存不是实际落盘确认，分享不是所有转发量。

Redis Lua 原子执行每日去重与总量/每日量累加，避免分步写入导致漏计。近七天只读聚合，无参数或人格上传。管理鉴权保持。

验证：前端真实交互、原子去重、日期边界、旧版本拒绝、管理鉴权、七日趋势及保存/取消分享口径。
