# 一键车格分析实施方案

用户已确认：点击即自动生成，取消所有身份、宣言和心情编辑；保留悬浮预览，突出趣味与自然传播。

- 入口统一为“车格分析”。按当前参数每次重新判断，自动生成身份、宣言、特点和点评。
- 视觉采用彩色车格鉴定卡：大称号、车与道路插画、身份标签、关键费用、趣味点评和扫码挑战。以第一人称表达，避免财富评级和虚构排名。
- 二维码固定指向 https://cost.ahopig.com/，不携带分享者的参数；本地生成并保留开源许可。
- 模态框只展示已生成图片和保存/可用时原生文件分享。图片生成完成即可长按保存；原生分享取消不降级下载，其他失败提供保存途径。
- 验证自动分析、零值、重新打开、无输入项、二维码实际解码、PNG 导出、桌面/手机以及原生分享成功/取消/不支持分支。
- 沿用上轮授权：完成后提交并推送远端，验证线上入口。

## 验证记录

- 20 个 Node 测试文件中 18 个通过；剩余 desktop-share、visit-counter 是上轮已经复现的旧断言失败。本次更新了与入口改名直接相关的 button-labels 断言，保留其他不相关测试。
- Playwright 桌面 1440px、手机 390px 验证：零编辑项、自动归类、参数变动后重新归类、实际 PNG 下载（1080×1920）、焦点恢复、非法输入、精确值、重置与历史链接。
- 文件分享以浏览器 API mock 分别验证成功、取消、失败、不支持。取消和失败不自动下载，保存按钮始终可用；这不代表已经在实体手机上验证系统分享面板。
- 使用独立 jsQR 解码器读取实际 Canvas 像素，原图及缩放至 540px、390px 均解码为 https://cost.ahopig.com/，无分享者参数。
- 完整卡片与桌面/手机浮层截图已人工检查，业务文件编码和 JavaScript 语法检查通过。
- 独立代码审查通过，无重要可行动问题。
- QR 库固定为 qrcode-generator 1.4.4，附 MIT 许可。本地 vendoring，无运行时 CDN 或外部制码请求。
