# 用车人格规则

各维度独立评分，选最高分作主称号，另取两个不同维度特点作为标签。并列按内部编号稳定排序，同输入不随机改变。阈值是产品趣味规则，不是行业排名；不能保证真实人群均匀分布，内测后再看集中程度。

| 维度 | 触发区间 | 人格 |
| --- | --- | --- |
| 年里程 | 40000 公里及以上 | 公路常驻嘉宾 |
| 年里程 | 20000～不足40000 公里 | 生活半径拓荒者 |
| 年里程 | 大于0、不足3000 公里 | 停车场隐藏款 |
| 年里程 | 3000～不足8000 公里 | 周末出逃选手 |
| 百公里能耗低 | 电车≤13 度；油车≤6 升 | 能耗管理大师 |
| 百公里能耗高 | 电车≥22 度；油车≥10 升 | 能量消耗大户 |
| 电价低 | 大于0且≤0.6 元/度 | 充电省钱掌门 |
| 电价高 | ≥1.5 元/度 | 充电尊享会员 |
| 计划持有 | ≥9 年 | 老车养成玩家 |
| 计划持有 | 大于0且≤4 年 | 换车体验派 |
| 停车费 | ≥2400 元/年且≥能源费1.5倍 | 车位包租侠 |
| 无突出维度 | 兜底 | 日子过得刚刚好 |

偏离越明显分数越高，不再按列表先到先得。能耗和电价特征要求正里程，电价特征另要求正能耗；零电价不发省钱称号；停车比较要求正能源费，避免除零。持有年限仅表示填写计划，不推断车辆寿命或报废。卡片附填写数据作为归类理由。能源类型、主称号及两个标签分别展示。
