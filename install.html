📱 安卓安装步骤

  1. 用安卓手机的相机或浏览器扫上方二维码（或点击"立即打开应用"按钮）
  2. 页面会在 Chrome 浏览器中打开，你会看到「车辆成本计算器」

  4. 选择「添加到主屏幕」或「安装应用」（不同 Chrome 版本字样略有差异）
  5. 弹出确认框点「安装」
  6. 返回桌面，你会看到名为「养车成本」的蓝色 ¥ 图标
